# Shopify-Themes

A collection of Shopify theme projects, templates, and utilities maintained in this repository.

## Overview

This repository contains one or more Shopify theme codebases and related assets (templates, sections, snippets, styles, and build/deploy helpers).

## Quickstart

- Preview locally with the Shopify CLI:

```bash
shopify theme serve
```

- Deploy changes with the Shopify CLI or your CI workflow:

```bash
shopify theme push
```
